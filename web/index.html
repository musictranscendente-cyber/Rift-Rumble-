Objetivo

Não existe barra de vida: cada golpe aumenta a % de dano. Quanto maior a %, mais longe você voa. Jogue os oponentes para fora da arena!

Controles

  • Joystick (lado esquerdo, em qualquer lugar): mover. Para baixo numa plataforma fina: descer. Para baixo no ar: queda rápida.
  • A: ataque básico (toque várias vezes para combo). Com o joystick para cima/baixo: golpe alto/baixo.
  • B: skill especial. Joystick para cima + B: skill de recuperação (para voltar para a arena).
  • Seta: pular (até 2 pulos; Zyra tem 3). Toque rápido = pulo curto.
  • Escudo: segure para defender. Escudo + joystick para o lado: rolar. Escudo + baixo: esquiva. No ar: esquiva aérea.
  • Estrela: ULTIMATE. A barra enche causando e recebendo dano.

Bordas e respawn

Chegue perto da borda caindo para se agarrar. Depois: para frente sobe, pulo salta, A sobe atacando.

Ao ser derrubado, você reaparece numa plataforma no alto com 0% e fica 2 s invencível (piscando).

Teclado (PC)

A/D/W/S ou setas: mover · Espaço: pular · J: ataque · K: especial · L: escudo · U: ultimate · Esc: pausa
